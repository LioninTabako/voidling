Jak działają mody?

Mod to lokalny skrypt JS w przeglądarce (localStorage). Może buffować gracza, reagować na fale / kille albo dodać ulepszenie do level-upu.

Po zmianie kodu: DODAJ / ZAPISZ → ODŚWIEŻ. Działa od następnego startu sektora.

API — wydarzenia

api.on(nazwa, fn)

  • start — start runu (buffy do api.P)
  • wave — nowa fala
  • kill — zabicie wroga
  • level — awans poziomu
  • midboss — spawn mid-bossa
api.on('start', function () {
  api.toast('Mod aktywny');
  if (api.P) { api.P.dmg *= 1.15; api.P.max += 20; api.P.hp = api.P.max; }
});
API — obiekty i rejestracja
  • api.P — gracz (hp, dmg, rate…)
  • api.toast(txt, ms) · api.log(...) · api.lang()
  • api.meta · api.E · api.U
  • api.registerUpgrade({ n, d, cat, a })
api.registerUpgrade({
  n: 'Mod Core', d: '+8% dmg (mod)', cat: 'dmg',
  a: function (s) { if (api.P) api.P.dmg *= (1 + 0.08 * s); }
});
